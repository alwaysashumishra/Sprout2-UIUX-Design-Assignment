## Figma workflow
1. Open Figma.
2. Create a new Design file.
3. Import each SVG into the canvas.
4. Use the SVGs as high-fidelity visual references and rebuild key sections with Auto Layout/components if the recruiter expects editable layers.
5. Keep 390x844 for mobile screens and 1440x900 for desktop homepage.
6. Use the design-system SVG as the token reference.
7. Connect the onboarding screens in Prototype mode:
   Welcome → What You Need → Mobile/OTP → KYC → Verification Waiting.

## Design decisions
- Single primary CTA.
- Visible risk information.
- Readiness checklist before KYC.
- Explicit waiting status to prevent the "app crashed" perception.
- Lightweight geometric mascot.
- No heavy video/ticker/pop-up stack.
